# angular-jira

Angular task/project management demo (TaskForge AI).

## Setup

```bash
pnpm install
pnpm start
```

App runs at [http://localhost:4200](http://localhost:4200).

## Build

```bash
pnpm build
```

Output: `dist/demo/browser`

## Vercel

- **Install command:** `pnpm install`
- **Build command:** `pnpm build`
- **Output directory:** `dist/demo/browser`
- Enable SPA rewrites so client routes fall back to `index.html`
